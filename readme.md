# Gabriel Alves Ribeiro — Front-End Developer Portfolio

Personal portfolio built to showcase my projects and background while I look for
my first internship opportunity in Front-End development.

**Live demo:** [(https://gabriel-alves-portfolio.vercel.app/)]

## About

I'm currently studying Software Engineering and completed a technical course in
Systems Analysis and Development in 2025. This portfolio is built with plain
HTML, CSS and JavaScript — no frameworks — as a way to practice and show what
I've learned so far.

## Built with

- HTML5 (semantic markup)
- CSS3 (custom properties, Flexbox, Grid, mobile-first responsive design)
- Vanilla JavaScript (no libraries or frameworks)
- [Google Fonts](https://fonts.google.com/) — Sora, Inter, JetBrains Mono

## Features

- Fully responsive layout (desktop, tablet, mobile)
- Dark theme with a blue accent palette
- Mobile navigation menu
- Scroll-reveal animations (respects `prefers-reduced-motion`)
- Sections: Hero, About, Tech Stack, Projects, Education, Contact
- Resume download button
- Basic SEO and Open Graph meta tags

## Project structure

├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
├── LICENSE
└── README.md


Everything is organized into a few simple files and folders on purpose, to
make the project easy to read, study and extend.

## Getting started

No build step or dependencies required. Just clone the repo and open the file
in your browser:

```bash
git clone https://github.com/gabriel707alves/gabriel-alves-portfolio.git
cd gabriel-alves-portfolio
```

Then open `index.html` directly, or serve it locally, for example with VS
Code's Live Server extension.
